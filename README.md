# Homelab-docs-

Documentation and configs from my self-hosted homelab, built for hands-on practice in networking, Linux administration, and Windows Server/Active Directory.

## Projects

- **[Active Directory Lab](./AD-Lab-Documentation.md)** — Windows Server 2022 domain controller in VirtualBox: OU design, user/group management, NTFS & share permissions, and Group Policy (drive mapping, security settings), including real troubleshooting of failed GPO deployments.
- **Scripts** — automation and utility scripts from ongoing homelab work.
- **configs** — service configuration files (Samba LXC, etc.) from the Proxmox server.

## Environment

Proxmox-based homelab running a mix of Linux containers/VMs and a Windows Server 2022 domain controller, used to build practical experience alongside CompTIA Network+ study.
